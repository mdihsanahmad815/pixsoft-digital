# PIXSOFT DIGITAL Website

A responsive, mobile-first multi-page website starter for PIXSOFT DIGITAL. Built with plain HTML, CSS, and JavaScript, so it can be uploaded directly to GitHub and hosted with GitHub Pages.

## Included pages
- `index.html` — Home
- `services.html` — Services
- `about.html` — About Us
- `team.html` — Our Team
- `portfolio.html` — Portfolio
- `pricing.html` — Pricing
- `contact.html` — Contact Us
- `quote.html` — Get a Free Quote
- `faq.html` — FAQ
- `privacy-policy.html` — Privacy Policy starter
- `terms.html` — Terms of Service starter

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a browser to preview.
3. Create a GitHub repository, for example `pixsoft-digital`.
4. Upload all files and folders from this project to the repository root.
5. In GitHub, open **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
7. Your site will be published at the GitHub Pages URL shown there.

## Important before launch
- Replace sample email/contact details and any sample project cards with your real information.
- Update privacy policy and terms to match your business and local legal requirements.
- Quote/contact forms are front-end demo forms. They validate fields and open WhatsApp with the submitted details; no information is stored on a server.
- This is a static website, so there is no admin panel or database yet.
