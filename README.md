# PIXSOFT DIGITAL

Responsive digital agency website for GitHub Pages.

## Pages
Home, Services, About, Team, Portfolio, Pricing, Contact, Free Quote, FAQ, Privacy Policy, Terms.

## Features
- Blue and white light-only design (no dark mode toggle)
- English/Bangla language toggle
- Responsive mobile navigation
- Glass-style animated buttons and hover effects
- Service quick links on homepage
- WhatsApp contact and quote form
- Logo and favicon in `assets/`

## Publish on GitHub Pages
Upload all files and the `assets` folder to the repository root. In Settings → Pages, select `main` and `/(root)`.
