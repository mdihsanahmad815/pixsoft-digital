# PIXSOFT DIGITAL

Responsive multi-page agency website for GitHub Pages.

## Structure
All website files are in the repository root, except the `assets/` folder, which contains the logo.

- HTML pages: Home, Services, About, Team, Portfolio, Pricing, Contact, Quote, FAQ, Privacy Policy, Terms
- `style.css` — shared styling
- `script.js` — navigation and WhatsApp quote form
- `assets/logo.png` — PIXSOFT DIGITAL logo

## GitHub Pages
Upload all files in this folder directly to the repository root. In Settings → Pages, select branch `main` and folder `/(root)`.

The quote form opens WhatsApp and does not save submissions to a database.
