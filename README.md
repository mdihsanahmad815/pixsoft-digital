# PIXSOFT DIGITAL

A responsive multi-page digital agency website with English/Bangla toggle, dark mode, service pages, portfolio, pricing, team, contact, FAQs, privacy/terms, and WhatsApp quote flow.

## Files
- HTML pages are in the repository root.
- `style.css` and `script.js` contain shared styling and interactions.
- `assets/` contains the PX logo PNG and favicon. Add your own project/team images here later.

## GitHub Pages
1. Upload all files and the `assets` folder to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
